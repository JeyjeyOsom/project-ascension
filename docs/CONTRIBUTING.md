# Contributing

## Branch Naming

feature/<name>

bugfix/<name>

hotfix/<name>

refactor/<name>

---

## Commit Messages

feat:

fix:

docs:

test:

refactor:

chore:

---

## Pull Requests

Every PR should include:

- Description
- Testing performed
- Screenshots (if UI)
- Related issue

---

## Coding Standards

- Use type hints
- Keep functions small
- Write meaningful names
- Add tests when appropriate
- Prefer composition over inheritance
- Keep documentation updated
